# Livewall releases

Livewall brings live video wallpapers to Windows. This repository hosts its official installers and update feed.

## Download

Get the latest installer from the [Releases page](https://github.com/5Y3D-Bilal/livewall-releases/releases/latest). Each release includes:

- `Livewall-<version>-x64.msi`: installer for 64-bit Windows
- `Livewall-<version>-x86.msi`: installer for 32-bit Windows
- `latest`: the update feed

## Supported platforms

- Windows (x64 and x86)

## Verify and update

Download the MSI that matches your Windows architecture from the Releases page, and install newer releases as they are published.

## Source code

This repository contains no source code, only download files and the update feed.
